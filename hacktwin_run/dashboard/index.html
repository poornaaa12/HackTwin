What is HackTwin for?

HackTwin is a software test bench for nand2tetris Hack CPU designs. It runs the same small programs on different CPU HDL versions, checks the results, counts simulated clock steps, and saves traces so you can see what happened.

In plain language

Change a CPU design → run the same tests → check that answers stay correct → compare how many simulator steps each version used.

This project simulates HDL. It does not test a physical chip or measure real clock speed, power, or chip area.

What does the ML model estimate?

The model estimates how many simulator cycles a collected Hack program will take to reach a repeated terminal loop. This is a prediction before running that exact case; it is not the measured simulator result or a physical speed estimate.

Checking the saved model…

How it learned

Public Hack programs were collected from GitHub. HackTwin ran eligible programs in its local Hardware Simulator with different starting RAM values, repeated the runs, and kept consistent cycle labels. The model learned from static program features and those simulator-generated labels.

Important limit: training currently covers a small set of programs and programs that reach a recognizable loop. The validation error is wide, so use the estimate as a demonstration and confirm important results by simulation.

Choose a collected program and starting RAM values, then select “Get an estimate”.
